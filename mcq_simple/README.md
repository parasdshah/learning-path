# AI for Developers: Simple MCQ Quiz
## Practical AI Skills for Enterprise Lending Software Engineers

---

### Overview

This quiz is designed for software developers who are learning to use AI coding assistants (**GitHub Copilot**, **Claude Code**, and **Google Antigravity**) in their day-to-day work building enterprise lending applications.

It focuses on **practical, real-world developer skills**:
- Knowing how and when to use AI tools effectively.
- Writing clear prompts and providing proper context.
- Debugging, testing, and reviewing AI-generated code.
- Keeping customer data and enterprise code secure.

---

### Quiz Structure

The questionnaire contains **30 straightforward multiple-choice questions** divided into three sections:

| Section | Focus Area | Questions |
|:---|:---|:---:|
| **Part 1: AI Tools & Foundations** | Core LLM concepts, Copilot modes (Agent/Ask/Plan), Claude Code CLI, and Google Antigravity. | Q1 – Q10 |
| **Part 2: Daily Coding, Prompting & Debugging** | Prompt engineering for code, context files (`CLAUDE.md`, `copilot-instructions.md`), and `/explain` / `/fix` debugging. | Q11 – Q20 |
| **Part 3: Testing, Code Review & Safe Usage** | Reviewing AI output, financial precision (`BigDecimal`), catching hallucinations, and data privacy. | Q21 – Q30 |

### Scoring Guide

- **27 – 30 Correct (90%+)**: **Advanced** — Highly confident using AI tools safely and productively.
- **24 – 26 Correct (80%+)**: **Proficient (Pass)** — Solid understanding of daily AI workflows.
- **20 – 23 Correct (67%–79%)**: **Needs Practice** — Review prompt structuring and code review checklists.
- **Under 20 Correct (<67%)**: **Beginner** — Revisit Track A Tier 1 & Tier 2 fundamentals.
