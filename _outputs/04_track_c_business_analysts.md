# Learning Track C — Business Analysts (AI-Informed Analysis)

> **Track Colour**: 🟨 Yellow  
> **Target Audience**: Business analysts, product owners, and requirements engineers who need to scope AI features, evaluate AI feasibility, write AI-ready requirements, and bridge technical/business stakeholders.  
> **Focus**: Thinking in AI, making informed decisions — NO coding required.  
> **Duration**: 10 weeks (4–6 hrs/week) | **Total Hours**: ~50 hours  
> **Free Content**: ~75%

---

## Track Overview

```
Week 1–3   → Tier 1: AI Literacy for Business (12–18 hrs)
Week 4–7   → Tier 2: AI-Informed Analysis (16–24 hrs)

```

> **Navigation**: BAs with existing AI knowledge may take the Tier 1 checkpoint quiz — score >80% to skip to Tier 2.

### Module 2.1 — Writing AI-Ready Requirements

```
📌 Course Title: Writing Requirements for AI/ML Features (Self-Study Workshop)
🔗 Platform: Self-curated reading + template creation
🔗 URL: N/A (internal workshop format)
⏱️ Duration: ~4 hours (reading + template creation + practice)
💰 Cost: Free
🎯 Mapped To: Track C → Tier 2 → AI-Ready Requirements
🏷️ Tags: requirements, non-deterministic, acceptance-criteria, hands-on
```

**Workshop Structure:**

| Traditional Requirement | AI-Ready Requirement |
|------------------------|---------------------|
| "System shall return correct results" | "System shall return factually accurate results >95% of the time, measured against golden dataset" |
| "Response time < 2 seconds" | "Mean response time < 2s; P99 < 5s; includes model inference + retrieval latency" |
| "System shall be user-friendly" | "AI responses shall maintain a CSAT score >4.2/5 across demographic groups with <10% variance" |

**Key Skills:**
- Defining success criteria for non-deterministic systems
- Specifying acceptable accuracy, latency, and error thresholds
- Documenting data requirements: what data, how much, how clean
- Writing AI user stories with testable acceptance criteria

**Deliverable**: Convert 5 existing requirements from current projects into AI-ready format.

```
✅ Verified: Yes — public YouTube content
🔊 Accessibility: Auto-captions available
```

**Self-Study Framework**: Use this decision matrix for any AI initiative:

| Dimension | Assessment Questions |
|-----------|---------------------|
| **Technical Feasibility** | Is the problem solvable with current AI? What's the SOTA accuracy? |
| **Data Readiness** | Do we have enough data? Is it labelled? Is it clean? |
| **Business Value** | What's the expected ROI? What's the cost of being wrong? |
| **Build vs Buy** | Is there an off-the-shelf solution? What's the TCO comparison? |
| **Risk** | What are the regulatory, ethical, and reputational risks? |
