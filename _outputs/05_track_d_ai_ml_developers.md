# Learning Track D — AI/ML Developers (Building AI Systems)

> **Track Colour**: 🟥 Red  
> **Target Audience**: Developers specialising in building AI/ML systems, training models, deploying ML pipelines, and creating AI-native applications.  
> **Focus**: Deep technical — designing, training, deploying, and monitoring AI systems in production.  
> **Duration**: 16 weeks (5–8 hrs/week) | **Total Hours**: ~100 hours  
> **Free Content**: ~68%

---

## Track Overview

```
Week 1–4   → Tier 1: AI/ML Engineering Foundations (20–32 hrs)
Week 5–10  → Tier 2: Applied AI/ML Engineering (30–48 hrs)
Week 11–16 → Tier 3: Advanced AI Engineering & Production Systems (30–48 hrs)
```

> **Navigation**: Engineers with existing ML/DL experience may take the Tier 1 checkpoint — score >80% on quiz + submit a working ML notebook to skip to Tier 2.

### 🏁 Tier 1 Checkpoint
- **Quiz**: 30-question MCQ covering ML concepts, Python libraries, data preprocessing, neural networks
- **Hands-on Project**: End-to-end ML project:
  1. Load a real dataset (from Kaggle)
  2. Perform EDA and data preprocessing
  3. Train at least 2 different models (e.g., Random Forest + Neural Network)
  4. Evaluate using appropriate metrics
  5. Present results with visualisations
- **Pass criteria**: >80% on quiz + working Jupyter notebook submitted
